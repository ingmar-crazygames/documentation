## Application Flow

Here's how the notification system works in this app:

1. **User authenticates** with JWT tokens for secure access
2. **Creates a task** which automatically triggers notification events
3. **In-app notifications** appear instantly in the notification feed
4. **Toast notifications** provide immediate feedback
5. **External users** receive email notifications when assigned tasks
6. **Users control** their notification preferences granularly

This creates a seamless notification experience where users stay informed without being overwhelmed.

## Core Implementation

### 1. JWT Authentication

The app uses [SuprSend's enhanced security mode](https://docs.suprsend.com/docs/client-authentication) with JWT tokens:

```javascript
const handleSignInSuccess = useCallback(async (userResult, distinctId) => {
  const token = await generateUserToken(distinctId, workspace);
  setUserToken(token);
  setCurrentUser({ distinctId, profile: userResult });
}, [workspace]);
```

**Why JWT over API keys?**
- **Enterprise Security**: ES256 elliptic curve signatures are unbreakable
- **Automatic Expiration**: Tokens expire and refresh seamlessly
- **Multi-tenant Support**: Isolated user contexts for different organizations

### 2. Task Creation & Notifications

When a user creates a task, the system automatically triggers notifications:

```javascript
const handleCreateTask = useCallback(async (taskData) => {
  const newTask = {
    id: Date.now().toString(),
    title: taskData.title,
    assignee: taskData.assignee, // Could be an email!
    status: 'todo'
  };
  
  setTasks(prevTasks => [...prevTasks, newTask]);
  await trackTaskCreated(newTask); // 🎯 Triggers notification cascade
}, [setTasks, trackTaskCreated]);
```

**What happens automatically:**
1. **Task created** → `TASK_CREATED` event fired to SuprSend
2. **In-app notification** → Appears instantly in the user's inbox
3. **External assignee?** → Email workflow triggers automatically
4. **Status changes** → `TASK_STATUS_CHANGED` event with real-time updates

#### Toast Notifications

```javascript
const ToastNotification = () => {
  const feedClient = useFeedClient();

  useEffect(() => {
    feedClient.emitter.on('feed.new_notification', (data) => {
      toast.custom(<ToastNotificationCard notificationData={data} />);
      feedClient.markAsSeen(data.n_id);
    });
  }, [feedClient]);

  return <Toaster />;
};
```

**Why toast notifications matter:**
- **Immediate Awareness**: Users know instantly when something important happens
- **Non-intrusive**: Brief, dismissible notifications don't interrupt workflow
- **Flexible**: Works with any toast library (react-hot-toast, react-toastify, etc.)

### 4. User Preference Management

Users get granular control over their notification experience:

```javascript
// Category-level preferences
await suprSendClient.user.preferences.updateCategoryPreference(
  category,
  preference
);

// Channel-level preferences  
await suprSendClient.user.preferences.updateChannelPreferenceInCategory(
  channel,
  preference,
  category
);
```

**Three levels of control:**
1. **Category Preferences**: "I want task updates but not marketing emails"
2. **Channel Preferences**: "Email me but don't send push notifications"
3. **Channel-within-Category**: "Email me task updates but not marketing emails"

**User Benefits:**
- **Personalized Experience**: Get only the notifications you want
- **Reduced Noise**: No more notification fatigue
- **Easy Management**: Intuitive interface for complex preferences

### Workflow Implementation

#### Task Assignment Workflow

When you assign a task to someone outside your system:

```javascript
// External assignee workflow
const trackTaskCreated = useCallback(async (taskData) => {
  // 1. Send in-app notification to current user
  await suprSendClient.track('TASK_CREATED', {
    task_title: taskData.title,
    task_id: taskData.id,
    user_name: 'User',
    timestamp: new Date().toISOString()
  });

  // 2. If assignee is external, send them an email
  if (taskData.assignee && isEmailAddress(taskData.assignee)) {
    const recipient = createRecipient(taskData.assignee, currentUser);
    
    // Trigger SuprSend workflow
    await triggerWorkflow('task_assigned_email', [recipient], {
      task_title: taskData.title,
      assignee_email: taskData.assignee,
      assigned_by: currentUser.name
    });
  }
}, [suprSendClient]);
```

#### Status Change Workflow

When users change task status:

```javascript
// Track task status changes with rich context
const trackTaskStatusChange = useCallback(async (taskTitle, oldStatus, newStatus, taskId) => {
  await suprSendClient.track('TASK_STATUS_CHANGED', {
    task_title: taskTitle,
    old_status: oldStatus,
    new_status: newStatus,
    task_id: taskId,
    user_name: currentUser.name,
    timestamp: new Date().toISOString()
  });
}, [suprSendClient]);
```
