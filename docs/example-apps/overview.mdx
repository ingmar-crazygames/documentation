# Example Applications

Learn from real-world applications that showcase SuprSend's notification infrastructure in action. These examples demonstrate best practices, common patterns, and practical implementation strategies you can apply to your own projects.

## Available Examples

### 🎯 Task Management App
**React + SuprSend Integration**

A production-ready task management application demonstrating:
- **JWT Authentication** with ES256 tokens
- **Multi-channel notifications** (email, in-app, push)
- **User preference management** with granular controls
- **External collaboration** with email-based task assignment
- **Real-time analytics** and event tracking

## Why These Examples Matter

### Production-Ready Patterns
These applications demonstrate real-world notification patterns that you'll encounter in production environments:

- **Security**: JWT tokens instead of basic API keys
- **Scalability**: Multi-tenant support and preference management
- **User Experience**: Granular control over notification settings
- **Developer Experience**: Clean, maintainable code architecture

### Learning Path
